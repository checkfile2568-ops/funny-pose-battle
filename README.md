# 🤪 ฮาท่าเทพ — เกมทำท่าฮาผ่านกล้อง (Funny Pose Battle)

เกมคลายเครียดสำหรับออฟฟิศ: AI ดูท่าผ่านกล้องหน้า ทำตามโจทย์ให้ทันใน 10 วินาที
ได้ภาพหลุด / GIF / **บัตรพนักงานเกียรติยศ** ไปแชร์ และสะสมคะแนนจนจบซีซั่น

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวเกมทั้งหมด (ไฟล์เดียว) — วางบน GitHub Pages |
| `gas/Code.gs` | Backend บน Google Apps Script: เก็บคะแนน ตารางอันดับ ห้องแข่ง |
| `gas/appsscript.json` | Manifest ของ Apps Script (เขตเวลา Asia/Bangkok) |

---

## ✨ มีอะไรบ้าง

- **ด่านประจำวัน** — ทั้งออฟฟิศได้โจทย์ชุดเดียวกันในแต่ละวัน เล่นซ้ำได้ไม่จำกัด ระบบนับเฉพาะเกมที่ดีที่สุดของวัน
- **ห้องแข่ง (แต่ละคนเล่นบนเครื่องตัวเอง)** — สร้างห้องแล้วส่งลิงก์หรือ QR ให้เพื่อน ทุกคนเริ่มพร้อมกันตามเวลาของเซิร์ฟเวอร์ ใครทำท่าผ่านก่อนจะได้ปาของ (🍅🩴🥚🐟) ใส่จอคนอื่น และได้ +50 แต้ม เมื่อทุกคนกด READY ครบ เกมจะเริ่มเอง
- **คู่หูกล้องเดียว** — 2 คนยืนหน้ากล้องเดียวกัน มี 3 ท่า: หัวใจ, ฟิวชัน, กอริลล่าคู่ คะแนนเข้าบัญชีทั้งสองคน
- **ฝึกซ้อม** — เลือกซ้อมทีละท่า มีเกจบอกว่าใกล้ผ่านแค่ไหน ไม่นับคะแนน
- **มีท่าทั้งหมด 12 ท่า**
  - หมวดใบหน้า: วิญญาณหลุดร่าง, แก้มป่องปลาปักเป้า (ทำตาเหล่ได้โบนัส), ยิ้มเห็นฟันครบ 32 ซี่, ปากเป็ดเซลฟี่, ลูกหมาอ้อนเจ้านาย
  - หมวดร่างกาย: กอริลล่าเรียกพวก, นกอินทรีปีกหัก, สายลับหลบกระสุน, โบกมือลาเงินเดือน
  - หมวดท่าคู่: หัวใจดวงโตที่ขาดหาย, ผสานพลังฟิวชัน, แก๊งกอริลล่า
- **เสียงทั้งหมดสังเคราะห์สดในเบราว์เซอร์** ไม่ต้องมีไฟล์เสียง ได้แก่ กลองรัวตอนนับถอยหลัง, เสียง "อ้าาาา" ที่ลากยาวตามแถบพลัง, เสียงทุบอก "ตุ้บ", เสียงสะบัดแขน "ฟึ่บ", ชัตเตอร์ "แชะ" + เสียงปรบมือ และเสียงตอนพลาด (แตรแป่ว / แพะร้อง / ไก่ขันหลงคีย์)
- **ถ่ายรูปอัตโนมัติ + ทำ GIF** — ท่าแบบค้าง ระบบเก็บช็อตที่ทำท่าได้สุดที่สุด ส่วนท่าแบบนับครั้ง ระบบอัด GIF 2 วินาทีให้
- **บัตรพนักงานเกียรติยศ** — บัตรมีรูป ชื่อ แผนก ตำแหน่งกวน ๆ ฉายา คะแนน และวันที่ (พ.ศ.) ดาวน์โหลดหรือแชร์ลงกลุ่มได้ทันที

### กติกาคะแนน
- ผ่านด่าน = 100 + โบนัสเวลา (สูงสุด 100) + โบนัสท่า แล้วคูณด้วยคอมโบ (ผ่านติดกันได้ ×1.1, ×1.2 … สูงสุด ×1.5)
- ถ้าไม่ผ่าน ได้แต้มปลอบใจตามแถบที่ทำได้ (สูงสุด 40)
- **คะแนนซีซั่น** = เอาคะแนนเกมที่ดีที่สุดของแต่ละวันมารวมกัน **วันสุดท้ายคูณ 2** (ปรับได้)
- ตารางอันดับมี 3 แบบ: ทั้งซีซั่น, สัปดาห์นี้ (จันทร์–อาทิตย์), วันนี้

## 🚀 ติดตั้ง (ประมาณ 10 นาที)

### ขั้นที่ 1 — ตั้ง Google Sheets + Apps Script
1. สร้าง Google Sheet ใหม่ แล้วตั้งชื่อ เช่น `ฮาท่าเทพ-คะแนน`
2. ไปที่เมนู **ส่วนขยาย → Apps Script** ลบโค้ดเดิมทิ้ง แล้ววางโค้ดจาก `gas/Code.gs`
3. (แนะนำ) ไปที่ ⚙️ การตั้งค่าโปรเจ็กต์ → ติ๊ก "แสดงไฟล์ appsscript.json" แล้ววางเนื้อหาจาก `gas/appsscript.json`
4. เลือกฟังก์ชัน `setup` → กด **เรียกใช้** → กดอนุญาตสิทธิ์
   ระบบจะสร้างชีต `Config`, `Scores` และ `Daily` ให้
5. กด **การทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → ประเภท: เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
6. คัดลอก URL ที่ลงท้ายด้วย `/exec`

### ขั้นที่ 2 — ใส่ URL ลงในเกม
เปิด `index.html` ค้นหาบรรทัดนี้ แล้ววาง URL ที่คัดลอกมา:
```js
const API_URL = '';   // ← วาง URL เว็บแอป Google Apps Script (ลงท้าย /exec)
```

### ขั้นที่ 3 — ขึ้น GitHub Pages
1. สร้าง repo ใหม่ เช่น `funny-pose-battle` แล้วอัปโหลด `index.html` (เก็บโฟลเดอร์ `gas/` และ `README.md` ไว้ใน repo ด้วยได้)
2. ไปที่ **Settings → Pages → Source: Deploy from a branch → main / (root)** แล้วกด Save
3. รอประมาณ 1 นาที เกมจะอยู่ที่ `https://<ชื่อบัญชี>.github.io/funny-pose-battle/`

> ⚠️ กล้องจะใช้ได้เฉพาะเว็บที่เปิดผ่าน **https** เท่านั้น ซึ่ง GitHub Pages รองรับอยู่แล้ว

## ⚙️ ตั้งค่าซีซั่น (ชีต `Config`)

| key | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `seasonName` | ซีซั่น 1 : ฮาท่าเทพ | ชื่อที่แสดงบนหัวเกมและบนบัตร |
| `seasonStart` / `seasonEnd` | วันนี้ / อีก 13 วัน | ใส่เป็นวันที่ได้ทั้ง ค.ศ. และ พ.ศ. เช่น `25/9/2569` (นับวันจบด้วย) |
| `finalDayMultiplier` | 2 | ตัวคูณคะแนนวันสุดท้าย |
| `hideLastDays` | 0 | ซ่อนตารางอันดับกี่วันสุดท้าย เช่น ใส่ 2 = ช่วง 2 วันสุดท้ายผู้เล่นจะเห็นแค่คะแนนตัวเอง แล้วค่อยเปิดผลหลังจบซีซั่น |
| `orgName` | ออฟฟิศฮาไม่หยุด | ชื่อหน่วยงานบนบัตรพนักงานเกียรติยศ |
| `difficulty` | normal | `easy` / `normal` / `hard` — ถ้าผู้เล่นบ่นว่ายากไป ให้เปลี่ยนเป็น `easy` ได้ทันทีโดยไม่ต้องแก้โค้ด |
| `roundsPerGame` | 5 | จำนวนท่าต่อเกม (3–10) |
| `prizeNote` | ประกาศรางวัลประจำสัปดาห์ทุกวันศุกร์ | ข้อความรางวัลที่แสดงในหน้าตารางอันดับ |

ค่าที่แก้จะมีผลภายใน 1 นาที (ระบบเก็บ cache ไว้ 60 วินาที)

**เมนู 🎮 ฮาท่าเทพ ในชีต**
- **สรุปอันดับลงชีต Standings** — สรุปอันดับซีซั่นและสัปดาห์ไว้พิมพ์หรือประกาศรางวัลวันศุกร์
- **เริ่มซีซั่นใหม่** — ย้ายข้อมูลเดิมไปเก็บในชีตที่มีวันที่ต่อท้ายชื่อ แล้วเริ่มนับคะแนนใหม่ (อย่าลืมแก้วันที่ใน Config ด้วย)

## 🧪 ทดสอบโดยไม่ใช้กล้อง
| URL | ผล |
|---|---|
| `index.html?mock` | ระบบทำท่าให้อัตโนมัติ ใช้เช็กว่าหน้าจอและขั้นตอนต่าง ๆ ทำงานครบ |
| `index.html?mock=keys` | กด **Space** ค้างไว้ = ทำท่าถูก, กด **R** = นับ 1 ครั้ง |
| `index.html?mock=fail` | ไม่ผ่านทุกด่าน ใช้ดูเสียงและหน้าจอตอนพลาด |
| `index.html?api=mock` | ห้องแข่งจำลอง มีบอท 2 ตัว (ไม่ต้องต่อ Google Sheets) |

ถ้ายังไม่ได้ใส่ `API_URL` เกมจะทำงานใน **โหมดทดลอง** คือเก็บคะแนนไว้ในเครื่องนั้นเครื่องเดียว และใช้ห้องแข่งไม่ได้

## 🛠️ แก้ปัญหาที่พบบ่อย
- **ไม่ขึ้นภาพกล้อง** — กดไอคอนแม่กุญแจหรือไอคอนกล้องที่แถบที่อยู่ แล้วเลือก "อนุญาต" ถ้ากล้องถูกโปรแกรมอื่นใช้อยู่ (เช่น Zoom หรือ Meet) ให้ปิดโปรแกรมนั้นก่อน
- **เปิดลิงก์จาก LINE แล้วกล้องไม่ทำงาน** — ลิงก์ห้องที่เกมสร้างให้จะมี `&openExternalBrowser=1` ต่อท้ายอยู่แล้ว ซึ่งจะบังคับให้เปิดใน Chrome หรือ Safari ถ้ายังไม่ได้ ให้กด ⋯ แล้วเลือก "เปิดในเบราว์เซอร์"
- **ครั้งแรกโหลดนาน** — ต้องดาวน์โหลดโมเดล AI ประมาณ 20 MB ครั้งเดียว ครั้งต่อไปเบราว์เซอร์จะจำไว้ให้
- **ท่าร่างกายไม่ผ่าน** — ถอยห่างจากกล้องให้เห็นตั้งแต่หัวถึงเอว และเปิดไฟให้สว่าง ลองดูเกจในโหมดฝึกซ้อมว่าติดที่แถบไหน
- **ท่ายากหรือง่ายเกินไป** — ปรับ `difficulty` ในชีต Config ได้เลย

## 🔒 ความเป็นส่วนตัว
- ภาพจากกล้องถูกประมวลผล **ในเครื่องผู้เล่นเท่านั้น** ไม่มีการส่งภาพหรือวิดีโอขึ้นเซิร์ฟเวอร์
- ข้อมูลที่ส่งไปชีตมีเพียง ชื่อเล่น แผนก คะแนน และชื่อท่า
- รูป บัตร และ GIF อยู่ในเครื่อง จะออกไปก็ต่อเมื่อผู้เล่นกดดาวน์โหลดหรือแชร์เอง

## 🧩 จุดต่อยอด (ค้นหาคำว่า `ต่อยอด:` ในโค้ด)
- **เพิ่มท่าใหม่** — เพิ่ม object ใน `POSES` (ส่วน `POSE-LIB` ใน index.html) และเพิ่มภาพการ์ตูนใน `ART`
- **เพิ่มท่าคู่** — ใส่ id ของท่าใน `DUO_POSES`
- **กำหนดว่าโหมดไหนนับคะแนนซีซั่น** — แก้ `MODES_COUNTED` ใน Code.gs
- **เพิ่ม API ใหม่** — เพิ่ม `case` ใน `route_()` ของ Code.gs

**เวลาอัปเดต Code.gs** ให้ไปที่ การทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข ✏️ → เวอร์ชัน: ใหม่ → ทำให้ใช้งานได้ วิธีนี้ URL เดิมจะใช้ต่อได้ ไม่ต้องแก้ index.html
